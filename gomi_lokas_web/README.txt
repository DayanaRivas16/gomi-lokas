# Gomi Lokas — página web empresarial

## Archivos
- `index.html`: estructura y contenido de la página.
- `style.css`: colores, diseño adaptable, animaciones y efecto parallax.
- `script.js`: menú móvil, animaciones al desplazarse y detalles interactivos.

## Cómo abrirla
1. Descarga y descomprime `gomi_lokas_web.zip`.
2. Abre la carpeta `gomi_lokas_web`.
3. Haz doble clic en `index.html`. Se abrirá en tu navegador.
4. Para editar el código, abre la carpeta en Visual Studio Code o en otro editor de texto.

No necesita Python ni instalación de paquetes para funcionar. Se recomienda conexión a internet para cargar las fuentes de Google y el mapa de Google Maps.

## Antes de presentar
- Sustituye el logotipo tipográfico temporal “GL!” por el logotipo oficial de Gomi Lokas.
- Revisa los nombres de productos y completa los precios reales. Los tres productos actuales son ejemplos visuales.
- Cambia las frases de opiniones por comentarios reales con permiso de sus autores.
- Confirma que la ubicación indicada sea correcta y que el punto de venta esté autorizado para aparecer como ubicación.
- Comprueba que Instagram, WhatsApp y el correo sean los datos definitivos.
- Las ilustraciones de gomitas están construidas con CSS y emojis como recurso temporal; puedes reemplazarlas por fotos reales de los productos.

## Publicarla en internet
Puedes subir los tres archivos a un servicio de alojamiento estático como GitHub Pages o Netlify. Conserva `index.html`, `style.css` y `script.js` en la misma carpeta para que las rutas funcionen.
